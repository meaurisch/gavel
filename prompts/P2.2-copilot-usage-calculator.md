# P2.2 — Standalone reusable Copilot session-usage calculator

> **Studio adjustment.** This is deliberately a STANDALONE module with zero
> dependency on setup-bench internals (so it can be pip-installed elsewhere) —
> keep studio's Python conventions (type hints, pydantic models, argparse/Typer
> with `--help`, exit codes 0/1/2). Only the thin adapter at the end touches
> setup-bench.

```
Build cost/copilot_usage.py as a STANDALONE, reusable module + CLI (usable outside setup-bench, in any project). Goal: turn a Copilot session's token usage into a cost figure in two units — AI credits and USD-equivalent — given per-model published rates.
Inputs it must support (pick whichever is available; make each a pluggable source):
- A pasted/exported VS Code "Chat Debug View" dump (parse per-interaction prompt/context/response token counts and sum them).
- The GitHub org Copilot usage report (per-user CLI token totals), via the documented API, for environments where I have access.
Config: a rates.yaml mapping model -> {input_per_mtok, output_per_mtok, cached_per_mtok, credits_per_usd: 100}. Output: a SessionCost(model, input_tokens, output_tokens, cached_tokens, usd, credits) and a one-line summary. 
Expose `copilot-usage from-debug <file> --model <m>` and `copilot-usage from-report --user <u> --since <t>`. Unit-test the math against a hand-worked example. Keep zero dependency on setup-bench internals so I can pip-install it elsewhere. Then add a thin adapter in setup-bench that calls it to fill CostRecord for copilot trials.
```
