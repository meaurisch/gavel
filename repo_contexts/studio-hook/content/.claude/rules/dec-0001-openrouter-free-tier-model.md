# [dec-0001-openrouter-free-tier-model] OpenRouter free tier; model id lives in config.yaml

The LLM is an OpenRouter free-tier model and config.yaml holds the id; moving to a paid model is a decision, not a bump

Read and change the LLM model id only in config.yaml, never in prose, and treat a move to a paid model as a decision for Morris, not a routine bump.
