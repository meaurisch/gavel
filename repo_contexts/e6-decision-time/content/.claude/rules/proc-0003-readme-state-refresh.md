# [proc-0003-readme-state-refresh] README "Current state" and "Next up" are refreshed in the session that changes them

A session that changes what a project is or does updates the README's "Current state" and "Next up" sections before it ends — divergence dies at root

Before finishing a session that changed source files, refresh README's "Current state" and "Next up" sections to match what actually changed.

If ignored: README state goes stale, and the next session starts from wrong assumptions about what this project currently is and does..
